      Admin Quick Guide

      Competition Manager: Use Set Active to switch what the public sees. Create New makes a fresh competition. Archive Current freezes the old one and creates a new active competition.

      Manage Gymnast(s): Add competitor number, club, and tags. Edit to fix typos. Deleting a roster entry removes their scores.

      Enter Score: Pick a category, select gymnast(s), then enter artistry, execution, difficulty, penalties, and total score.

      Stream Controls: Choose a mode (Welcome, Idle, Scoreboard, Mix, Announcement) and select the current performer when spotlighting.

      Display Settings: Default is Auto rows + 100% font + 7s page time. Auto uses screen height (5 under 1300px, 6 at 1300-1899px, 7 at 1900px+). Use Manual for fixed 4-10 rows, adjust font 85-120%, set page time 4-12s, and control scoreboard Category/Grade plus Overall vs By-Grade ranking, then click Apply.

      Lock Admin: Use this when stepping away to re-enable the PIN gate.

      Clear Competition Data: Wipes gymnast(s) and scores for the active competition. Use only when starting fresh.
